# Birthday Experience

A responsive, multi-stage birthday greeting website built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For best results, run a simple local server (for example, VS Code Live Server).

## Included
- Intro screen with animated gift illustration
- Mystery gift reveal
- Interactive candles and wish reveal
- Three-question birthday quest
- Interactive memory cards
- Opening letter animation
- Grand finale with fireworks
- Personalized birthday card export as SVG
- Responsive mobile styling, reduced-motion support, optional synthesized sound
- No backend or build tools required

## Customize
Edit `index.html` to change the message copy. Search for `Your person` to change the sign-off. Edit the memory-card `data-memory` attributes for personalized notes. Change colors in `:root` in `style.css`.

Note: the card exports as an SVG image. The page link is only shareable as a public link after you host the folder on a static hosting service.
